# Digital Verification Using SystemVerilog & UVM

This repository contains my hands-on assignments and projects from the **Digital Verification Diploma by Eng. Kareem Wasseem**.

The diploma progresses from **fundamental verification concepts using SystemVerilog to building complete Universal Verification Methodology (UVM) environments**.

The repository documents my learning journey through verification planning, testbench development, constrained-random verification, functional coverage, and UVM-based verification.

## Topics Covered

- Verification Planning
- SystemVerilog Fundamentals for Verification
- Tasks, Functions, and Subroutines
- Self-Checking Testbenches
- Object-Oriented Programming (OOP)
- Constrained-Random Verification
- Functional Coverage
- SystemVerilog Assertions (SVA)
- UVM Components and Testbench Architecture
- Sequences, Sequencers, Drivers, and Monitors
- Scoreboards and Reference Models
- Complete UVM Verification Environments

## Tools & Technologies

- Universal Verification Methodology (UVM)

- Linux Mint

- Git & GitHub

## Simulation & Development Workflows

The assignments use a mixture of **QuestaSim-based workflows and Linux command-line workflows with open-source tools**.

QuestaSim is used for complete UVM environments, while selected assignments explore fully open-source implementations. Where applicable, assignment folders include commands or scripts for compiling and running simulations.

A key goal is to become confident working with open-source tools and reproducible command-line workflows, while gaining practical experience with commercial verification tools.

Tool requirements and supported features vary by assignment; refer to the instructions in each folder.

## Repository Progression

The repository is organized by topic, starting with SystemVerilog verification planning and subroutines, followed by constrained-random verification and functional coverage. Further assignments and projects will be added as I progress toward complete UVM environments.
